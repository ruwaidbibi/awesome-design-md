# Where these came from

The 74 `DESIGN.md` files in this directory are vendored from
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md),
MIT licensed, Copyright (c) 2026 VoltAgent. The licence is kept alongside them
in `LICENSE`.

They are vendored rather than fetched so this repository clones and runs in one
step, offline, with no submodule. To pull updates, replace this directory from
upstream and keep `LICENSE` and this file in place.

Each file is a design-system analysis of a public brand's website. leadsites
uses them as a *visual language only*: the generation prompt forbids copying any
source brand's name, logo, wordmark, product names or marketing copy onto a
generated site, and forbids implying any affiliation.
